# Code of Conduct

This project welcomes people of every background. Be respectful, be specific, and assume good faith.

- Critique ideas, not people. Sharp technical disagreement is welcome; personal attacks are not.
- No harassment, discrimination, or demeaning behavior.
- Respect privacy. This project is about data sovereignty; act like it.

Violations can be reported by opening a confidential issue or contacting the maintainer. Maintainers may edit, remove, or reject contributions and comments that violate this code.

Adapted in spirit from the Contributor Covenant.
